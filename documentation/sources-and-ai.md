# Sources and AI Assistance

## External materials

- Banana puzzle service: [API documentation](https://marcconrad.com/uob/banana/doc.php) and [JSON API endpoint](https://marcconrad.com/uob/banana/api.php). Puzzle images and availability are provided by that service.
- The Banana API documentation states the service is provided as-is and must not be used for commercial applications; this project is a non-commercial university prototype.
- Runtime libraries are listed in `package.json` and their licenses/terms should be checked before redistribution.
- The jungle world, explorer, interface artwork, styles, and sample SVG puzzle are original project-authored SVG/CSS/HTML assets. There are no hotlinked stock illustrations.
- DM Sans and Paytone One are referenced from Google Fonts when online; the page falls back to local generic fonts if unavailable. Confirm the font licenses if redistributing bundled font files (none are bundled here).

## AI assistance
